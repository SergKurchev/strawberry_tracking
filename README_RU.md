# Strawberry Tracker & Pose Estimator

Система визуальной одометрии и долгосрочного отслеживания (Long-term Tracking), оптимизированная для работы с синтетическими данными Isaac Sim. Система генерирует измерения (measurements) для факторного графа GTSAM.

## Математическая архитектура (Dual-Pipeline)

Проект реализует гибридный метод извлечения признаков для одновременного решения задач Re-ID объектов и SLAM:

### 1. Детекция и Сегментация
Используется YOLOv8 для генерации множества ограничивающих рамок $B = \{b_1, ..., b_n\}$. Для исключения дубликатов применяется NMS с порогом $\tau_{iou}$. Каждой рамке сопоставляется локальная маска для сегментации текстуры ягоды.

### 2. Экстракция признаков (DISK)
Применяется раздельное извлечение ключевых точек для двух разных задач:
* **Feature-Track (Локально):** Извлечение точек $p_{local}$ внутри масок $B$. Математически это фильтрация входного изображения $I$ через бинарную маску объектов $M$: $I_{masked} = I \odot M$. Это гарантирует, что дескрипторы принадлежат только ягодам.
* **SLAM-Track (Глобально):** Извлечение точек $p_{global}$ со всего кадра $I$ для захвата геометрии сцены (стены, пол, листья), что критично для стабильности одометрии при малом количестве ягод в кадре.

### 3. Сопоставление и Re-ID (Hungarian Algorithm)
Для связывания ягод между кадрами $t-1$ и $t$ строится матрица весов $W$, где $w_{ij}$ — количество соответствий LightGlue между рамками $i$ и $j$. Решается задача линейного назначения:
$$\max \sum_{i,j} w_{ij} x_{ij}, \quad \text{s.t.} \sum_i x_{ij} = 1, \sum_j x_{ij} = 1$$
Результатом является сохранение стабильного `global_id` для каждого объекта.

### 4. Восстановление позы (Essential Matrix & MAGSAC)
По глобальным инлайерам $x_1, x_2$ рассчитывается Существенная матрица $E$ через минимизацию ошибки репроекции:
$$x_2^T E x_1 = 0, \quad E = [t]_{\times} R$$
Используется алгоритм **MAGSAC** для фильтрации аутлайеров. При среднем смещении точек $\Delta p < \tau_{motion}$ движение признается нулевым ($R=I, t=0$) для защиты от дрейфа в статике.

## Инструкция по использованию API

### Основной цикл в коде
Метод `forward` инкапсулирует всю логику обработки кадра.

```python
from strawberry_tracker import StrawberryTracker
from ultralytics import YOLO

# 1. Инициализация
tracker = StrawberryTracker(YOLO('best.pt'), device='cuda', config=config)

# 2. Матрица K (Интринсики из Isaac Sim)
K = np.array([[1649.25, 0, 960], [0, 1649.25, 540], [0, 0, 1]])

# 3. Обработка (в цикле)
# img_rgb: массив [H, W, 3]
R, t, ids, boxes, m1, m2, i1, i2, debug = tracker.forward(img_rgb, K)
```

**Возвращаемые значения:**
* `R`, `t`: Относительная трансформация камеры (Rotation 3x3, Translation 3x1).
* `ids`: Список глобальных ID для ягод в текущем кадре.
* `boxes`: Координаты рамок `[x1, y1, x2, y2]`.
* `i1, i2`: Координаты точек-инлайеров (геометрически верные совпадения).

## Запуск тестирования и Экспорт данных

Для запуска массовой обработки датасета COCO и генерации файлов для GTSAM используйте скрипт `test_on_coco.py`.

### 1. Подготовка
Убедитесь, что в `config.yaml` настроены:
- `test_frame_range: [start, end]` — диапазон кадров.
- `export_data: true` — флаг сохранения результатов.

### 2. Запуск
```bash
uv run python test_on_coco.py
```

### 3. Результаты экспорта (`exported_data/`)
После прогона в папке появятся три файла:
* `poses.csv`: Таблица относительных перемещений (одометрия).
* `tracking.json`: История перемещения каждой ягоды (ID + BBoxes).
* `inliers.json`: Пары 2D-точек для каждого кадра (Landmarks).

## Повторное использование данных (Re-import)

Пример того, как загрузить экспортированные данные обратно для анализа или передачи в GTSAM:

```python
import pandas as pd
import json

# Загрузка одометрии (CSV)
df = pd.read_csv('exported_data/poses.csv')
for _, row in df.iterrows():
    # Извлечение вектора трансляции
    translation = np.array([row['tx'], row['ty'], row['tz']])
    # Извлечение матрицы поворота
    rotation = row[['r11','r12','r13','r21','r22','r23','r31','r32','r33']].values.reshape(3,3)

# Загрузка трекинга (JSON)
with open('exported_data/tracking.json', 'r') as f:
    data = json.load(f)
    # Получить боксы для кадра 065
    frame_boxes = data['frame_065']
    for obj in frame_boxes:
        print(f"ID: {obj['id']}, BBox: {obj['bbox']}")
```
